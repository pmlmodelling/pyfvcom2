Installation
============

For end users, the easiest way to install *PyFVCOM2* is using *Conda*. This will install *PyFVCOM2* and all its dependencies
into a clean environment and make it available to use. Developers who wish to work with the source code directly should clone
the `repository from GitHub <https://github.com/pmlmodelling/pyfvcom2>`_ and install it manually. Both use cases are described below.
