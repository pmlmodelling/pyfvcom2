PyFVCOM2
========

PyFVCOM2 is a Python package for working with FVCOM (Finite Volume Community
Ocean Model) data. It provides tools for reading FVCOM meshes and outputs,
building forcing files, interpolating oceanographic data, analysing tides, and
preparing common FVCOM inputs.

PyFVCOM2 is the successor to PyFVCOM. It keeps the focus on practical FVCOM
pre- and post-processing while modernising the package structure and
documentation.
